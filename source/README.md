# Source artwork

- `hildegard-pose-sheet-chroma.png`：图像生成工具输出的洋红背景九姿态母版。
- `hildegard-pose-sheet.png`：经色键移除、柔化边缘及去色溢处理后的 RGBA 母版。
- `hildegard-animation-sheet-chroma.png`：挥手与待机专用的 4×2 洋红背景动画母版。
- `hildegard-animation-sheet.png`：去除色键后的挥手与待机 RGBA 动画母版。
- 图集构建入口：`python3 scripts/build_assets.py`

母版采用原创 Q 版设计：深绿色眼睛、简洁本笃会服饰与头顶灵视火焰；站立待机时持书与牧杖。悬停行使用落地挥手帧，不含跳跃姿势。生成时未指定或仿制任何单一历史画像。
